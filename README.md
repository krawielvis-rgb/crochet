# Crochet

Crochet is a clean, community-minded blogging platform for publishing thoughtful writing and discovering new voices.

## Project brief

The project will give writers an inviting space to create, organize, and share posts, while readers can browse topics, follow authors, and join conversations. The experience should feel calm, fast, and focused on the work itself.

### Core features

- Rich post editor with drafts, tags, and cover images
- Public author profiles and a personalized reading feed
- Search and topic-based discovery
- Comments and lightweight community interaction
- Responsive design for comfortable reading on any device

Crochet aims to make publishing personal stories and useful ideas feel simple, beautiful, and connected.
