Crochet stitch abbreviations cheat sheet

The shorthand every pattern assumes you already know.

Words by Crochet Journal • Updated September 11, 2026

Patterns lean heavily on abbreviations to stay readable, and while every pattern should define its own terms, it helps enormously to already recognize the most common ones on sight.

The basics

  • ch — chain
  • sl st — slip stitch
  • sc — single crochet
  • hdc — half double crochet
  • dc — double crochet
  • tr — treble (triple) crochet

Shaping terms

  • inc — increase (two stitches in one)
  • dec — decrease (two stitches worked together)
  • sk — skip
  • rep — repeat
  • st(s) — stitch(es)

US versus UK terms

This is the abbreviation trap that catches even experienced crocheters. A UK single crochet is a US slip stitch, and a UK double crochet is a US single crochet, everything is shifted by one. Always check which convention a pattern is using before you start, most designers state it near the top.

Once these become automatic, a pattern stops looking like code and starts reading like a story.

When a pattern uses something unfamiliar

If you hit an abbreviation you do not recognize, check the pattern's own key first, designers sometimes invent shorthand for a specific stitch combination used repeatedly in that piece.
