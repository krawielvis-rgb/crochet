Crochet Baby Blanket

A soft, beginner-friendly crochet baby blanket with a simple shell texture, gentle shaping, and a scalloped border.

Complete tutorial roadmap

Prepare your yarn, hook and measurements. Build the blanket with an even shell rhythm, check the width as it grows, then add the border and finish securely.

Materials & preparation

DK baby yarn, a 5.5 mm hook, scissors and a tapestry needle. Choose a soft washable yarn and keep the label for care instructions.

Core pattern / method

Start with a foundation chain sized for your desired width while keeping the stitch repeat consistent. Work the setup row evenly, then repeat the shell texture across the blanket. Keep the first and last stitch easy to see and check the width every few rows.

Step-by-step

  1. Choose soft yarn and make a small tension swatch.
  2. Chain the foundation to the desired blanket width.
  3. Work the setup row and count the stitches.
  4. Repeat the shell texture while keeping both edges straight.
  5. Continue until the blanket reaches the desired length.
  6. Add the scalloped border and weave in all ends.

Checkpoint

Check that the edges remain parallel and every shell follows the same rhythm. If the blanket narrows, count the first and last stitches before continuing.

Troubleshooting

If the shells look crowded, loosen your tension or test a larger hook. If the fabric feels too loose, try a smaller hook. Correct count problems as soon as you notice them.

Finishing

Weave in all ends securely on the back. Work the scalloped border carefully around corners so the edge stays flat. Shape flat only if the yarn label permits it.

Variations & next projects

Try two neutral shades, gentle stripes, or a contrasting border. The same shell rhythm can be adapted for stroller blankets and lap blankets.

Care & storage

Wash and dry according to the yarn label. Store the blanket folded loosely so the border keeps its shape.

Final notes

Record your hook size, stitch count and any tension adjustment that worked. Those notes make the next version easier.
